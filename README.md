# Retail Sales Analysis - Power BI Dashboard

## 📊 Project Overview
This project is a comprehensive corporate retail data analytics dashboard built using Power BI. It extracts and analyzes market distribution datasets to compare traditional retail stores with economic discount lounges.

## 🛠️ Tools & Technologies Used
* **Power BI** (Data Modeling, DAX, Interactive Visualizations)
* **Power Query** (Data Cleaning & Transformation)
* **Excel / CSV** (Data Sources)

## 📌 Key Insights & Features
* Performance analysis by Category, Payment Method, and Time.
* Interactive filters (Slicers) for Seasons and Payment Methods.
* Key performance cards tracking Total Sales and Total Quantity.
